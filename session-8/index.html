Attention, in the order it was launched

Vanilla attention was never wrong. It was expensive. Every mechanism below is somebody looking at that bill (n² compute, and a KV cache that grows with every token, every layer and every head) and trying to pay less of it. They are laid out by the date each one first appeared in public, checked against the paper on arXiv or the official release. Read the timeline top to bottom and you can watch the field change its mind.

1 · Exactness2014–2019: attention everywhere, every pair
2 · Length2019–2021: sparse, linear, positions that stretch
3 · Memory back2019–2024: MQA → GQA → MLA, sinks, stretch RoPE
4 · Both at once2024–2026: hybrids, learned sparsity, compression

MHA keeps 2·L·H·d per token. MQA: 1 K/V head; GQA: 8; MLA: 512 + 64 dims latent; sliding window: 4,096 tokens kept; NSA/CSA-style: blocks of 16 compressed (plus a 4K window); hybrid DDDG: only 1 in 4 layers keeps a cache, the rest hold a fixed state.

What the timeline shows that a list does not

  1. The field changed its mind four times, and the order is the lesson. First it wanted exactness (2014–2017): every token reads every token. Then it wanted length (Sparse Transformer 2019, Longformer and linear attention 2020), and gave up exactness to get it. Then it wanted memory back: MQA in 2019 was ignored until decoding cost dominated, then GQA (2023) and MLA (2024) cut the cache while keeping exact attention. Now it wants both at once: hybrids with Gated DeltaNet layers, learned sparsity (NSA, DSA) and compressed sequences (DeepSeek-V4).
  2. FlashAttention (2022) is the hinge. Before it, approximate attention (Reformer, Performer, linear) was the road to length. After it, exact attention was fast enough again. So the 2022–2024 work moved from "approximate the scores" to "keep exact scores, shrink what we store". You cannot see that turn in a list grouped by family.
  3. The ideas come back, renamed. Fixed sparse patterns (2019) return as learned block selection (NSA, 2025). Linear attention (2020) returns as the delta rule (2021) and then Gated DeltaNet (2024) inside hybrids. Transformer-XL's segment memory (2019) returns as V4's Memory Stream. Each comeback arrives when hardware or a new trick removes the reason it was abandoned.
  4. Position has its own clock. Positions went from learned tables (2017) to rotations (RoPE, 2021), to stretching rotations (PI, NTK, YaRN, 2023), to throwing them away after training (DroPE, Dec 2025). Every step is the same question asked again: how far past the training length can we go?
  5. What comes next, from the trend: the remaining bill is the cache that still grows with every token in the attention layers. The next mechanisms will (a) store less per token than a latent (more compression, as V4's HCA already does), (b) put fewer attention layers into each hybrid, and (c) learn which tokens deserve a cache entry at all, rather than selecting them at read time.
